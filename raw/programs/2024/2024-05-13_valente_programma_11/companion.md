## Cosa c'è nel piano (`Programma 11 (fatto da Francesco Valente).ods`)

Il foglio di calcolo contiene:

- **Foglio "Massimali"**: 1RM di riferimento usati per il calcolo delle
  percentuali del programma, più tabelle di incremento MAV (MAV5 +2-3%,
  MAV3 +3%, MAV2 +3-4%).
- **Fogli "Settimana 1" … "Settimana 9"**: piano seduta per seduta con
  colonne Giorno / Esercizio / %1RM / Peso reale (P.t.W.) / Ripetizioni /
  Note / Done. La colonna `Done` è un flag 0/1 che ho compilato durante
  l'esecuzione — quindi il file è **piano + log di esecuzione insieme**.
- **Foglio "Copia di Settimana 9"**: variante parziale della sett. 9,
  probabilmente una deviazione dal piano registrata durante l'ultima
  settimana. Solo la metà delle sedute è marcata `Done=1`.

## Struttura settimanale osservata

- **Lunedì**: squat schema principale (volume alto → intensità crescente
  nelle settimane), panca a piramide o con elastico, pull-up, curl.
- **Martedì**: panca parallele presa media, stacco schema principale,
  squat complementare, pull-down tricipiti.
- **Giovedì**: squat MAV / lavoro tecnico (fermi 2", d.3, squat fermo
  sopra e sotto 3"), panca MAV + back-off, hyperextension o front squat,
  pull-over o stacco rumeno.
- **Venerdì**: stacco tecnico (3" incassata / 3" salita), panca presa
  media fermo 3", ausiliari (squat bulgaro, military press, croci,
  affondi).
